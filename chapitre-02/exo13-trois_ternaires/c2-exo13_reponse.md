# Resultat
Apres l'execution du programme (./programme) on obtient:
```
Entrer un premier nombre12
Entrer un deuxieme nombre7
7
12
pair
7objets
```
A partir des valeurs arbitraires(a=12 et b=7) o constate que:
- La premiere terniaire (le plus petit) renvoie comme resultat:
```
7
```
- La deuxieme terniaire (plus grand) renvoie comme resultat:
```
12
```
- La troisieme terniaire(parite du premier entier(a)) renvoie :
```
pair
```
- La quatrieme terniaire (Cas des accords a partir du deuxieme entier(b)) renvoie :
```
7objets
```
