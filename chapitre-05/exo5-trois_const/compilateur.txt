Regle :
const avant l'étoile : c'est la variable designee qui est constante. On ne peut pas ecrire a travers le pointeur, mais le pointeur peut changer de cible.
const apres l'étoile : c'est le pointeur lui-meme qui est constant. Il ne peut pas changer de cible, mais on peut ecrire dans la variable.
Avec les deux (c) : les deux sont bloques.
