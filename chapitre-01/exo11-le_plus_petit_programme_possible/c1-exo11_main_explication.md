# pourquoi on ne peut plus ren retirer
Parceque chaque element est crucial pour le respect du standart C++
1. *le type de retour* de la fonction main (int)
2. *l'espace entre le int et main* car sans ca le compilateur lirait "intmain"
3. *main* est le nom impose par le standart et le point d'entree que recherche l'editeur de liens
4. *les parentheses* pour les parametres. Elles sont importantes et obligatoires pour toutes declaration de fonction
5. *les acolades* pour le corps de la fonction. Sans elles on aura une simple declaration de fonction.
