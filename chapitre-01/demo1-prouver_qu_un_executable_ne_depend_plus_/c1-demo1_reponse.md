# Explications
- Pour la compilation j'ai utilise la commande: `clang++ -std=c++17 -Wall main.cpp -o programme`
- le resultat de l'executable grace a la commande (`./programme`) est : 
```
demo 1
demo 2
```
- Pour la suppression du code source grace a la commande (`rm main.cpp`)
- Apres la relance de l'executable une seconde grace a la commande (`./programme`) on obtient le resultat:
```
demo 1
demo 2
```
# Conclusion
l'executable est un programme autonome qui decoule de la traduction en langage machine d'un code source.
A cet effet livrer un programme n'oublige pas a livrer son code car l'executable suffit pour utiliser le logiciel.
